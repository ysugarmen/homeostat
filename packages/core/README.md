# @homeostat/core

The library behind [homeostat](https://www.npmjs.com/package/homeostat): the entry and config schemas, validation, scoring, selection, the secret and risky-content scanners, topic files and the multi-repo layout, the daily run's drafting, the deep dive, bootstrap's file pickers, and the GitHub and Bitbucket providers.

Most people want the `homeostat` command instead. This package is published for it and for tools built on the same knowledge-base format; its API follows the CLI's version and may change before 1.0.

Apache-2.0. Source: <https://github.com/ysugarmen/homeostat>.
